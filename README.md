# ForecastAudit

Учебный проект по анализу больших данных: сравнение прогнозов семи глобальных
метеомоделей с фактическими наблюдениями станций Белгидромета. Показывает,
какая модель точнее в каждой области Беларуси.

- `/` — метеопост хозяйства: прогноз метеослужбы против показаний полевой станции.
- `/audit.html` — аудит точности: карта областей, таблица ошибок, рейтинг моделей, сводки станций.

## Что нужно на машине

- Docker Desktop (или Docker Engine с Compose на Linux).
- Для запуска из среды разработки — ещё Java 17.

## Запуск целиком одной командой

Так проект поднимается на любой машине и на хостинге; Java и Maven ставить не нужно.

```bash
git clone https://github.com/Pasholu/pogoda.git
cd pogoda
docker compose --profile full up -d --build
```

Сайт откроется на `http://localhost:8080`. Первая сборка занимает несколько минут.

На хостинге перед запуском задайте свой пароль базы:

```bash
cp .env.example .env
```

и впишите в `.env` значение `DB_PASSWORD`.

Обновление после новых изменений в репозитории:

```bash
git pull
docker compose --profile full up -d --build
```

## Запуск для разработки

База — в Docker, приложение — из среды разработки:

```bash
docker compose up -d db
```

Затем запустите `WeatherAppApplication` (или `./mvnw spring-boot:run`).
База слушает порт 5434, чтобы не спорить с PostgreSQL, установленным в системе.

## База данных

Схему создаёт и обновляет само приложение при старте (миграции Flyway в
`src/main/resources/db/migration`). Вручную ничего создавать не нужно.

| Таблица | Что хранит |
|---|---|
| `station` | станции каталога, их координаты и адрес запроса к узлу Белгидромета |
| `observation` | сводки станций: одна строка — один срок наблюдения |
| `forecast` | прогнозы моделей на сроки наблюдений, выпущенные за 1, 2 и 3 суток |
| `ingest_run` | журнал выгрузок: когда, сколько строк, чем закончилась |

Наполнение идёт автоматически:

- при каждом старте приложение догружает последнюю неделю — на новой машине база наполняется сама за пару минут;
- сводки Белгидромета забираются каждые 3 часа, прогнозы — каждый час;
- повторная выгрузка тех же сроков строки не дублирует.

Отчёт и сводки станций читаются из базы. Если источник данных недоступен,
сайт продолжает показывать то, что уже накоплено.

### Догрузка истории

Месяц истории задним числом (допустимо от 1 до 92 суток):

```bash
curl -X POST "http://localhost:8080/api/admin/backfill?days=30"
```

Состояние базы и последние выгрузки:

```bash
curl http://localhost:8080/api/admin/ingest
```
